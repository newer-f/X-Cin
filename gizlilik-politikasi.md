# XÇin Gizlilik Politikası / Privacy Policy

**Son güncelleme / Last updated:** 28 Ekim 2026

---

## Türkçe

XÇin (mağaza adı: "XÇin — Translation Blocker for X"), Chrome tarayıcısı için
geliştirilmiş bir eklentidir. Amacı, X (Twitter) sayfalarında otomatik çeviri
özelliğindeki seçilen dillerden çevrilen gönderi ve yorumları (alıntılanan
gönderiler dahil) kullanıcının tercihine göre gizlemektir. Eklenti arayüzü
Türkçe ve İngilizce olarak kullanılabilir; X arayüz dili ne olursa olsun
çalışır.

### Veri Toplama

**XÇin hiçbir kullanıcı verisi toplamaz.**

- Kişisel bilgi (ad, e-posta, konum vb.) toplanmaz.
- Tarama geçmişi, gezinme davranışı veya ziyaret edilen sayfalar izlenmez.
- Analitik, istatistik veya telemetri verisi toplanmaz.
- Reklam veya pazarlama amacıyla hiçbir veri kullanılmaz.

### Yerel Olarak Saklanan Ayarlar

Eklenti, yalnızca kullanıcının tercihlerini kaydetmek için tarayıcının yerleşik
eşitleme deposunu (`chrome.storage.sync`) kullanır:

- Engellenen diller listesi
- "Yorumlar modu" açık/kapalı durumu
- Eklentinin aktiflik (açık/kapalı) durumu
- Arayüz dili (Türkçe/İngilizce) tercihi

Bu ayarlar yalnızca kullanıcının kendi tarayıcısında (ve kullanıcının kendi
Chrome hesapları arasındaki eşitlemede) saklanır. **Geliştirici bu verilere
erişemez.**

### Ağ İletişimi

Eklenti **hiçbir ağ isteği yapmaz**. Hiçbir veri bir sunucuya, üçüncü tarafa
veya geliştiriciye gönderilmez. Eklenti kendi adına internet bağlantısı
kullanmaz (yalnızca X sayfasının kendisi internet gerektirir).

### Üçüncü Taraflarla Paylaşım

Hiçbir veri toplanmadığı için üçüncü taraflarla hiçbir veri paylaşılmaz,
satılmaz veya aktarılmaz.

### Çerezler ve İzleme

Eklenti çerez oluşturmaz ve herhangi bir izleme teknolojisi kullanmaz.

### Değişiklikler

Bu politika değişirse, güncel sürüm bu sayfada yayımlanır.

### İletişim

Gizlilikle ilgili sorularınız için eklentinin Chrome Web Mağazası sayfasındaki
"Destek" sekmesini kullanabilirsiniz.

## English

XÇin (store name: "XÇin — Translation Blocker for X") is an extension for the
Chrome browser. Its purpose is to hide posts and comments (including quoted
posts) translated from selected languages in the auto-translate feature on
X (Twitter) pages, according to the user's preference. The extension UI is
available in Turkish and English and works regardless of the X interface
language.

### Data Collection

**XÇin does not collect any user data.**

- No personal information (name, email, location, etc.) is collected.
- Browsing history, navigation behavior or visited pages are not tracked.
- No analytics, statistics or telemetry data is collected.
- No data is used for advertising or marketing.

### Locally Stored Settings

The extension only uses the browser's built-in synced storage
(`chrome.storage.sync`) to save the user's preferences:

- List of blocked languages
- "Comments mode" on/off state
- Extension active (on/off) state
- Interface language (Turkish/English) preference

These settings are stored only in the user's own browser (and in syncing
between the user's own Chrome accounts). **The developer cannot access this
data.**

### Network Communication

The extension makes **no network requests**. No data is sent to any server,
third party or the developer. The extension itself does not use any internet
connection (only the X page itself requires internet).

### Third-Party Sharing

Since no data is collected, no data is shared, sold or transferred to third
parties.

### Cookies and Tracking

The extension does not create cookies and does not use any tracking
technology.

### Changes

If this policy changes, the updated version will be published on this page.

### Contact

For privacy-related questions, you can use the "Support" tab on the
extension's Chrome Web Store page.
